# AI&DS CGPA / SGPA Calculator

CGPA and SGPA calculators for the Artificial Intelligence and Data Science
(AI&DS) curriculum under Regulation 2022.

## Features

- Browser-based calculator with semester selection and grade simulation.
- R implementation for interactive or non-interactive calculations.
- Subject and credit data stored in `semesters.csv`.
- SGPA and CGPA calculated as credit-weighted averages.
- Performance classification based on the final CGPA.
- CSV report export from the R implementation.

## Files

| File | Description |
| --- | --- |
| `index.html` | Standalone web calculator. |
| `cgpa_calculator.R` | R-based calculator and demo script. |
| `semesters.csv` | Semester, subject, code, and credit data. |
| `cgpa_report.csv` | Generated by the R script; not committed. |

The curriculum reference PDF is intentionally excluded from version control
through `.gitignore`.

## Web calculator

Open `index.html` directly in a web browser. No build step or web server is
required.

## R calculator

Install R, then run the demo from this directory:

```bash
Rscript cgpa_calculator.R
```

The demo calculates Semester 3 using sample grades and previous SGPAs. It
creates `cgpa_report.csv` in the project directory.

To use the calculator interactively from an R session:

```r
source("cgpa_calculator.R")
run_calculator(
  csv_path = "semesters.csv",
  sem_no = 3,
  prev_sgpas = c(8.4, 8.1)
)
```

For a non-interactive run, provide one grade for every subject in the selected
semester:

```r
run_calculator(
  csv_path = "semesters.csv",
  sem_no = 3,
  demo_grades = c("O", "A+", "A", "B+", "O", "A+", "A", "O"),
  prev_sgpas = c(8.4, 8.1)
)
```

When calculating Semester 1, omit `prev_sgpas`. For later semesters,
`prev_sgpas` must contain one SGPA for every preceding semester.

## Grade scale

| Grade | Points |
| --- | ---: |
| O | 10 |
| A+ | 9 |
| A | 8 |
| B+ | 7 |
| B | 6 |
| C | 5 |
| U | 0 |

## Formulas

```text
SGPA = sum(subject credits * grade points) / sum(subject credits)
CGPA = sum(semester SGPA * semester credits) / sum(semester credits)
```

The R implementation rounds SGPA and CGPA to two decimal places.

## CGPA classification

| CGPA range | Classification |
| --- | --- |
| 9.00 and above | Outstanding |
| 8.00-8.99 | First Class with Distinction |
| 6.50-7.99 | First Class |
| 5.00-6.49 | Second Class |
| Below 5.00 | Below Passing |
